# L'Addition

Jeu de gestion de cafe qui vire a l'horreur psychologique. Une barista endettee
tient sept jours dans un cafe qui est un seuil vers le monde des esprits.
References : Dead Plate et Papers Please.

## Jouer au prototype

Ouvre **`index.html`** dans un navigateur (c'est un site statique, aucune
installation). Le prototype couvre le MVP : la boucle de service d'une journee.

- Clique un client pour le selectionner.
- Compose sa boisson avec les ingredients (l'ordre n'a pas d'importance, seuls
  les ingredients comptent : validation souple).
- Sers avant que sa patience tombe a zero.
- Plus tu accumules d'erreurs, plus la lucidite baisse et plus l'ambiance du
  cafe bascule vers l'etrange.

Recettes : Espresso (tasse, cafe) · Americano (tasse, cafe, eau chaude) ·
Latte (tasse, cafe, lait, mousse) · Cappuccino (tasse, cafe, mousse, cacao).
